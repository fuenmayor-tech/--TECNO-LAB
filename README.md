# --TECNO-LAB
TECNO LAB es una aplicación para aprender Tecnología e Informática en la básica primaria, de 1.° a 5.°. Aquí conoces el computador y sus partes con modelos 3D con realidad aumentada, realidad virtual y practicas con lecciones, videos, juegos, un simulador y retos de creación. Cada grado tiene sus propios temas y 5 modelos 3D nuevos.
